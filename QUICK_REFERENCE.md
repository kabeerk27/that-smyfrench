## 🎨 Quick Customization

### Change Colors
Edit `tailwind.config.ts`:
```typescript
colors: {
  primary: '#1e3a8a',      // Change blue
  secondary: '#fbbf24',     // Change amber
}
```

### Update Email
Find in:
- `src/components/Footer.tsx`
- `src/app/contact/page.tsx`
- Replace with your email

### Update Phone
Find in:
- `src/app/contact/page.tsx`
- Replace with your phone

### Change Course Price
Edit `src/app/courses/page.tsx`:
```typescript
price: "$299"  // Change price
```
